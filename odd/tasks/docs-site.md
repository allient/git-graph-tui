# Documentation site (Starlight)

Objective: a simple, English documentation site for git-graph-tui built with Astro Starlight, inside a Better-T-Stack-style monorepo that keeps the Rust workspace as is, with screenshots of the app's main components.
Branch: docs/starlight-site, one PR against main. Delivery: ask-on-risk. Tests: `bun run build` (Starlight build, link check), the screenshot script, and the Rust gate (`cargo fmt --all --check`, `cargo machete`) to prove Rust tooling is unaffected.

## Specs

- **S1** "on monorepo create an awesoem docuemntation for thsi project https://starlight.astro.build/es/ using this docuemntaton and code for nnwo all in englsish". A Starlight site whose content comes from README.md, AGENTS.md, integrations/herdr/README.md and the code (keys, config, CLI flags); all pages in English.
- **S2** "monorepo shuld be simialr as teh ones used by better t stack. for docuemtnation and be compatible with rust". Root `package.json` with Bun workspaces `apps/*` and `packages/*` and a version catalog, `turbo.json` with `build`/`dev`/`preview` tasks (a `deploy` task comes with the deploy CI later), the site in `apps/docs`. The Cargo workspace (`crates/`, `Cargo.toml`, `Cargo.lock`), CI, cargo-dist and the release stay unchanged and keep working.
- **S3** "the docuemntation shoudl be simple and I want it show screenshots of main componens of the cli app". Few pages, short; screenshots of the main components (graph with badges, context menu, Source Control pane, commit details, find, dialog), generated by a script from a scratch fixture repo so they can be regenerated.
- **S4** "later i am going to connect ci cd to deploy on cloudflare or can be deployed on any place by free?". The site builds to static files (`apps/docs/dist`), deployable for free on Cloudflare (Workers static assets or Pages), GitHub Pages, Netlify or Vercel. No deploy CI now (assumption: the user connects it later); docs explain how.
